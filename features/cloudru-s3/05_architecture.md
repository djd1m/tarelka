# Архитектура Cloud.ru S3

## Компоненты

Общая фабрика createPhotoS3Client получает проверенный StorageConfig.
API использует PutObject, DeleteObject, HeadObject, HeadBucket, GetObject presigner
и paginator ListObjectsV2. Recognizer использует GetObject, PutObject и DeleteObject.
StorageObjectLister экспортируется из photo/storage-object-lister.ts для проверки пагинации.
Файл photo-store-minio.ts сохраняет экспорт существующей фабрики для совместимости вызовов
и использует общий S3 клиент внутри.

## Ошибки и повторы

SDK повторяет запрос до трёх попыток, connectionTimeout 2000 мс, requestTimeout 15000 мс.
404 при HEAD означает отсутствие. Ошибки доступа, сервера и транспорта передаются вызывающему.
DELETE отсутствующего объекта идемпотентен по контракту S3.
Общий deletePhotoS3Object перед каждым DELETE проверяет GetBucketVersioning.
Enabled, Suspended и ошибка запроса прерывают удаление без фиксации purged.
Состояние версионирования не кэшируется между операциями удаления.
Существующий best-effort cleanup в API обрабатывает ошибку на уровне бизнес-операции.
В POST /scans три ветви отката перехватывают и журналируют отказ удаления,
сохраняя ответы 202 при повторе, 429 при исчерпанной квоте и 503 при отказе БД.
Удаление по сроку и аккаунту подтверждает успешное удаление до записи в БД.

## Развёртывание

Cloud.ru параметры задаются через S3_* в .env. Приложение использует сеть egress.
MinIO ограничен профилями test/local-storage и сетью private.
Параметры локального пользователя остаются N4_S3_*.
Новый бакет рекомендуется выделить специально для фотографий «Тарелки».
Версионирование на нём должно никогда не включаться. Runtime получает GetBucketVersioning.
Публичные маршруты приложения читают подписанные ссылки на сервере.

## Проверки

Транспортные тесты исполняют AWS SDK на локальном HTTP S3 fixture.
Конфигурационные тесты проверяют оба сервиса.
Compose проверяется на разрешение production-профиля без локальных root-секретов
и на test-профиль с локальными реквизитами.
Регрессия покрывает старые потоки сканов, карточек и удаления.
