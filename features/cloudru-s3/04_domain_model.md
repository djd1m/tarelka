# Модель хранения

Существующие сущности Photo, Recognition и ShareCard используют строковые ключи объектов.
Photo содержит object_key и normalized_object_key. Ключ включает идентификаторы сессии
и распознавания. В PostgreSQL сохраняются срок хранения и состояние физического файла.

StorageConfig задаёт endpoint, region, bucket, accessKey, secretKey, forcePathStyle.
API записывает оригиналы и изображения карточек, подписывает GET и убирает орфаны.
Recognizer читает оригинал, записывает нормализованное изображение, удаляет фото по сроку
и при удалении аккаунта. Подтверждение физического удаления предшествует purged.

Инварианты — приватный доступ, прежние ключи объектов, повторяемое удаление,
передача отказов доступа и транспорта обработчикам повторов.
Схема PostgreSQL и форматы клиентских ответов соответствуют существующим контрактам.
