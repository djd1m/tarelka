## Why

Основная конфигурация «Тарелки» жёстко связана с локальным MinIO.
Владелец запросил поддержку Cloud.ru S3 на основе рабочего подхода clipmkr,
с применением feature-adr и OpenSpec для контроля изменений.

## What Changes

- Параметры S3 задают endpoint, регион, бакет, адресацию и ключи Cloud.ru.
- Общий S3-клиент обслуживает операции API и воркера, включая удаление и список объектов.
- Основной Compose подключается к внешнему бакету, MinIO используется локальными тестами.
- Проверки покрывают конфигурацию, операции хранения, ошибки и пагинацию.
- Инструкция описывает настройку бакета и перенос существующих фото с сохранением ключей.

## Impact

API, recognizer, общий пакет, Docker Compose, env-пример, тесты и инструкция запуска.
Feature ADR — features/cloudru-s3. Checkpoint 0 и 1 подтверждены владельцем.
Реализация и локальные проверки выполнены, результаты независимой проверки находятся в QE-отчёте фичи.
